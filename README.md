# Spanish Word Anki Maker

# Installation
This project uses Python and [uv, the new Python package management tool](https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_1). 

## Mac
You may already have Python installed. Open up a terminal and type "python3". To install uv, use [this link](https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_1) and follow the instructions.

## Windows
I recommend [Chocolatey](https://chocolatey.org/install). It's a command line installation tool. From a command prompt you can run `choco install python`. Then follow these instructions to install [uv](https://docs.astral.sh/uv/getting-started/installation/#__tabbed_2_2).
